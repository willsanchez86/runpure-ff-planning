# Code-repo kit

Copy these files into `runpure-ff-backend` and `runpure-ff-frontend` (same paths). Add a repo secret `PLANNING_REPO_TOKEN` with read access to `runpure-ff-planning`, and require the `planning-refs` check on `main`.

`init-runpure-backend.ps1` creates `runpure-ff-backend` and copies these files into it. Run it from this folder (ETL spec §13, step 1).
